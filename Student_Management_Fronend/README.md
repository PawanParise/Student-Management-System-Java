# 💻 EduPulse — Student Management Frontend (React + Vite)

## Tech Stack
- **Framework**: React 19 + Vite
- **Icons**: Lucide React
- **Design System**: Vanilla CSS tokens, glassmorphism, responsive grid
- **Theme**: Dark & Light mode toggle with localStorage persistence

## Running the Application
```bash
npm install
npm run dev
```
Open `http://localhost:5173/` in your browser.

## Features
- Dynamic CRUD operations connected to Spring Boot REST endpoints
- Real-time search and course filtering
- Multi-column sorting
- CSV roster export
- Detail profile modal & safe delete confirmation
- Live backend connection health monitoring
